Responsive Images

Learn image sizing, cropping and fitting

1. Responsive Image

The image fills its container because width is set to 100% and height is controlled.

2. Object Fit: Contain

The complete image stays visible inside the box. Empty space may appear around it.

3. Object Fit: Cover

The image covers the entire area. Some edges may be cropped to preserve its proportions.

4. Natural Image Ratio

With automatic height, the image keeps its intrinsic aspect ratio instead of using a fixed-height crop.
