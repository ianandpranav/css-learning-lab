
# Responsive CSS

Techniques for creating responsive layouts that adapt to different screen sizes and devices using HTML and CSS.

## Focus

- Responsive web design
- Mobile-first design
- Media queries and breakpoints
- Flexible dimensions and relative units
- Responsive typography and images
- CSS Grid and Flexbox

## Topics Covered

- Responsive navigation and card layouts
- Responsive forms and image galleries
- Hero sections, headers, and footers
- Blog layouts and dashboards
- Login and registration pages
- Product landing pages and pricing tables
- FAQ, team, services, and portfolio sections
- Testimonials and newsletter sections
- Mobile, tablet, and desktop layouts

## Practice

This folder contains 25 HTML practice files covering responsive CSS concepts and practical page layouts.

The exercises focus on building flexible, user-friendly interfaces that work across different screen sizes.

## Technologies

- HTML5
- CSS3
- Media Queries
- CSS Grid
- Flexbox
