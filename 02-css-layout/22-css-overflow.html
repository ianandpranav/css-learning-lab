CSS Overflow

Learn how content behaves when it exceeds an element's dimensions.

1. Overflow: Visible

This content is taller than its container. With visible overflow, extra content can appear outside the container.

Default behavior: overflowing content remains visible.

2. Overflow: Hidden

This content exceeds the container height. The overflowing portion is clipped and cannot be accessed through scrolling.

Extra content is clipped.

3. Overflow: Scroll

This content is intentionally longer than the box. Scroll inside this container to read the remaining text. Practice scrolling vertically and horizontally.

A scroll container is created even when scrolling isn't needed.

4. Overflow: Auto

This content is wider than the container. Scroll horizontally to see the complete content. Resize the browser to observe the behavior.

Scrollbars appear when the content requires them.
