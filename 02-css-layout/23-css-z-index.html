CSS Z-Index

Learn how z-index controls the stacking order of overlapping elements.

1. Different Z-Index Values

Red — z-index: 1
Blue — z-index: 2
Green — z-index: 3

The green box appears on top because it has the highest z-index among these overlapping elements.

2. Negative Z-Index

Content in front

This text appears above the orange background box.

A negative z-index can place an element behind other content within its stacking context.

3. Try It Yourself

  • Change the red box to z-index: 5.
  • Change the blue box to z-index: 10.
  • Observe which box appears on top.
  • Remove position: absolute and see what changes.
