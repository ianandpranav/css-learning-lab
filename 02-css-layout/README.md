# CSS Layout

A hands-on practice collection for learning CSS layout techniques, positioning, overflow, and responsive page structures.

## 🎯 Learning Objectives

- Understand how elements are arranged on a webpage.
- Practice Flexbox for one-dimensional layouts.
- Use CSS Grid for rows and columns.
- Control element positioning and stacking order.
- Handle overflowing content.
- Build layouts that adapt to different screen sizes.
- Combine layout concepts in practical webpage examples.

## 📚 Topics Covered

| Topic | Key Concepts |
|---|---|
| CSS Layout Fundamentals | Containers, spacing, element arrangement |
| Flexbox | `display: flex`, `gap`, `justify-content`, `align-items`, `flex-wrap` |
| CSS Grid | `grid-template-columns`, `grid-template-rows`, `fr`, `minmax()` |
| Responsive Layouts | Media queries, flexible layouts, breakpoints |
| Positioning | `static`, `relative`, `absolute`, `fixed`, `sticky` |
| Overflow | `visible`, `hidden`, `scroll`, `auto` |
| Stacking Order | `z-index`, overlapping elements, stacking contexts |
| Practical Layouts | Dashboards, sidebars, cards, navigation and content sections |

## 🗂️ Practice Files

This folder contains individual HTML exercises and layout demonstrations.

- **HTML practice files:** Work through the numbered examples in order.
- **Flexbox vs CSS Grid:** Compare one-dimensional and two-dimensional layouts.
- **Holy Grail Layout:** Practice a header, sidebars, main content and footer.
- **CSS Positioning:** Experiment with different positioning properties.
- **CSS Overflow:** Explore how overflowing content is displayed.
- **CSS Z-Index:** Understand overlapping elements and stacking order.
- **Layout Practice Dashboard:** Combine Flexbox, Grid, positioning and responsive design.

*Note: See the HTML files in this folder for the complete list of exercises.*

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- CSS Media Queries

## 🚀 How to Practice

1. Open an HTML exercise.
2. Read the CSS and identify the layout properties.
3. Change values such as `gap`, `flex`, `grid-template-columns` and `position`.
4. Preview the page in a browser.
5. Resize the browser to test responsive behavior.
6. Experiment with your own improvements.

## 💡 Key Takeaway

Flexbox is especially useful for arranging elements along one dimension, while CSS Grid is designed for layouts across rows and columns. Positioning, overflow and responsive techniques help create more controlled and adaptable interfaces.

## 📌 Goal

Build a strong foundation in CSS layouts before moving on to advanced CSS concepts and practical frontend projects.
